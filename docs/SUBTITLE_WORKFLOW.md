# AutoFlow：完全依据已有字幕制作

## 仅导出文件

“仅译文”可以直接采用所选中文字幕的正文和时间轴，跳过 ASR 和正文翻译；原文或双语输出仍需要原语言文字，不能由中文字幕替代。需将音轨上的时间轴方式设为“完全采用字幕文字和时间轴”。

批量处理选择“仅字幕文件”，内容可选双语、仅原文、仅译文。不生成配音或视频成品；仅原文跳过正文翻译，另外两种按需使用翻译服务。命名在“设置 → 自动处理 → 字幕文件”选择音频原名、内容命名或自定义；分轨字幕沿用音轨文件名。ASR 仍可能需要内部工作音频，这不属于输出音频成品。

行宽在“混音与字幕”设置为 8–500 字符。修改已有项目时保存到当前项目或两者，再重新导出；默认值不会追溯修改旧项目。

已有可信字幕时，不必让 ASR 重新生成同一份台词。字幕不需要覆盖每秒音频：没有字幕的停顿、音乐、呼吸段不应因此被自动补写。

这里的“完全依据字幕”是指句子正文与导入时间；后续配音整体偏移、自动加速和字幕可读性设置仍可能调整成品播放/显示时间。需要贴近文件时间轴时，核对偏移和字幕设置，不要把导入时间等同于强制 TTS 时长。

LRC 通常只有开始时间，结束时间由下一条开始或最后一条估计时长推导；SRT/VTT 等带明确起止的文件按其时间导入。不要声称 LRC 拥有并精确保留了不存在的结束时间。

## 每轨怎样设置

1. 在“工作台 → 批量处理”扫描作品目录，检查本次选择的全部音轨。
2. 每条音轨的“台本或字幕文件”选择与它对应的 SRT、VTT、ASS/SSA 或 LRC。
3. “时间轴”选 **“完全采用字幕文字和时间轴（不运行 ASR）”**。
4. 核对每轨“字幕语言”：中文字幕必须选 **中文**，不要被源音频是日语误导。
5. 确认扫描摘要提示全部音轨已有时间轴字幕，再加入队列。

| 输入 | 正文处理 |
|---|---|
| 每轨都是中文字幕 | 字幕正文与时间戳直接导入，跳过 ASR 和正文翻译，进入配音 |
| 每轨都是日文或英文字幕 | 跳过 ASR，翻译字幕正文后配音 |
| 中文与一种源语言字幕混合 | 跳过 ASR；保留中文，只翻译非中文部分 |
| 日文、英文字幕混合 | 当前合并项目只支持一种源语言，明确报错；请分轨处理或统一语言标记，不会偷偷重跑 ASR |
| 缺少部分音轨字幕 | 不属于完整字幕模式；补齐或取消选择缺字幕音轨，再运行 |
| 纯 TXT 无时间戳，或选择重新定时 | 仍可能需要 ASR；不能把它当作直接使用字幕时间轴 |

合并时只给每条字幕加上该音轨在合并音频中的起点偏移。字幕解析失败会报错，不会通过丢弃字幕改跑 ASR 来“修复”。字幕原文中的重复、重叠也会按输入保留，不擅自去重；请先确认字幕本身正确。

作品名和曲目标题翻译是另一个可选功能。若希望整个任务都不调用翻译服务，请同时关闭“设置 → 自动处理”中的作品名称和音轨标题翻译。

## 旧任务已经走错流程怎么办

旧版曾把“所有字幕都有，但语言不同”误判为覆盖不足。不要直接继续旧任务的 ASR/翻译成果：

1. 备份旧成品；重新扫描作品，而不是继续旧队列快照。
2. 核对每条字幕，特别是中文译名中包含“・”等符号的文件；此符号已不再被当作日文假名。
3. 确认全部采用字幕文字和时间轴、语言正确后，显式选择“重做并替换本工具生成的旧结果”，再执行。

重做会替换工具输出，请先备份。程序不会在升级时自动重写源音频、源字幕或既有成品。对仍保留旧错误导入状态的任务，会给出重做提示，避免继续生成重复配音。
