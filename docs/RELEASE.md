# ASMR Dubber 1.0.0

1.0.0 将原先独立的 AutoFlow 批量工具整合进 ASMR Dubber，并补齐单作品与批量作品共用的设置、缓存、日志和任务控制。以下内容以 0.7.3 为对比基准。

## 相比 0.7.3 的主要变化

### 批量处理进入主界面

- “工作台”现在包含“单个作品”和“批量处理”两个入口，不需要再单独运行 AutoFlow 命令行程序。
- 可以扫描已经解压的 DLsite 作品目录，选择音频版本，并决定是否包含特典、样本、Free Talk 和闹钟等附加音轨。
- “本次将处理的音轨”支持拖动排序；触屏或键盘操作可以使用上下按钮。
- 程序会为每条音轨匹配 SRT、VTT、ASS/SSA 或 LRC，判断中文、日语或英语，并允许逐条更换、改语言或关闭。
- 完整的中文字幕直接建立中文时间轴并跳过 ASR 与翻译；日语或英语字幕跳过 ASR；没有字幕的音轨仍按当前识别设置处理。
- 视频任务直接显示推荐图片路径和预览，也可以换用其它作品图片或黑色背景。
- 成品可以合并成一部、每条音轨分别输出，或同时保留分轨和合并版。
- 处理队列支持拖动排序、编辑、取消编辑、移除、标记重新处理和取消当前任务。
- “设置 → 自动处理”可以分别控制是否翻译作品文件夹名称和音轨标题，并保存批量任务的固定规则与默认值。

### 单作品配音与混音

- “生成中文配音”和“混音与输出”拆成两个阶段。修改时间、音量、声道路由或字幕后可以直接重新混音，不再重复运行 TTS。
- 中文配音新增“上一句结束后再播放下一句”排程方式：不自动加速，发生冲突时顺延下一句，避免中文互相覆盖。
- 原有“尽量放入原时间窗口”仍可使用，并继续支持整体偏移、最大自动加速倍速和达到上限后允许重叠。
- 混音、中文克隆音轨、字幕和导出表使用同一套实际排程，避免不同输出使用不同落点。

### 兼容性和界面

- MP3 标题或封面等文字标签损坏时，程序会替换无法解码的元数据，避免可正常播放的音频因标签编码错误而无法新建项目。
- 批量音轨和任务卡片在多次刷新后仍保持一次操作只移动一格；Windows 路径在卡片中使用稳定的正斜杠显示。
- README 增加单作品、ASR、翻译、TTS、混音和批量处理的真实界面截图；使用、配置、排错和架构文档同步更新。

## 模型和下载兼容性

1.0.0 没有增加新的大型模型，也没有改变基础、推荐和进阶三种安装方案的固定模型范围。原有 Parakeet、Kotoba-Whisper v2.2、Faster-Whisper large-v2、ASMR Whisper VAD、Qwen3 ForcedAligner 和 IndexTTS2 安装内容继续沿用。

安装器和“设备与模型”页面继续使用同一套 ModelScope 优先、断点续传、大小与 SHA-256 校验流程。已经完整安装的模型不会因为升级到 1.0.0 而重新下载。

## 下载

### Windows

从本 Release 的 Assets 下载 `ASMR-Dubber-windows-portable.zip`：

1. 在 Windows 设置中启用长路径；
2. 把压缩包完整解压到短且可写的目录，例如 `D:\Apps\ASMR-Dubber`；
3. 运行 `ASMR-Dubber-Setup.exe`，选择基础、推荐或进阶；
4. 安装完成后运行 `ASMR-Dubber.exe`。

压缩包包含启动器、便携 Python 引导环境、源码、脚本和文档，不包含大型模型、用户项目或 API Key。Windows 10/11 不要求预装 Python、Git、FFmpeg、CUDA Toolkit 或 PowerShell 7。

### 从 0.7.3 升级

1. 关闭 ASMR Dubber 和正在运行的模型服务；
2. 备份需要保留的项目以及 `.asmr-dubber/config`；
3. 把 1.0.0 压缩包解压并覆盖旧程序文件，不要删除原有 `.asmr-dubber`；
4. 重新运行 `ASMR-Dubber-Setup.exe`，选择原来的安装方案。

Setup 会修复程序环境并复用已经通过校验的依赖和模型。旧项目会在首次打开时按兼容规则读取，不需要手工修改 `project.json`。

### Linux

下载本 Release 的源码压缩包并解压，然后运行：

```bash
bash scripts/linux/setup.sh 推荐
bash scripts/linux/run-ui.sh
```

Linux 支持仍按 x86_64 环境提供；本地 NVIDIA 模型需要可用的显卡驱动。

## 安装方案

| 方案 | 内容 | 建议可用空间 |
|---|---|---:|
| 基础 | 程序、网页、音频工具和外部 API 客户端，不含本地识别模型 | 5 GB |
| 推荐 | 基础 + Parakeet CTC 1.1B JA GAL + Parakeet TDT/CTC 0.6B JA；NVIDIA 电脑再安装 IndexTTS2 | 35 GB |
| 进阶 | 推荐模型 + Kotoba-Whisper v2.2 + Faster-Whisper large-v2 + ASMR Whisper VAD ONNX + Qwen3 ForcedAligner 0.6B；NVIDIA 电脑再安装 IndexTTS2 | 50 GB |

更完整的安装条件、离线模型包和网络策略见[安装指南](INSTALLATION.md)。

## 数据和密钥

项目、模型、缓存、设置和密钥默认保存在程序目录中。API Key 以明文位于 `.asmr-dubber/config/secrets.json`；请保护该目录，不要把它加入公开压缩包、Git 仓库或网盘。

删除整个程序文件夹即可卸载。删除前请先备份需要保留的项目和密钥。
