# ASMR Dubber 3.0.0

完整的变更列表见[更新日志](https://github.com/EveningStudy/asmr-dubber/blob/v3.0.0/CHANGELOG.md)。

## 主要变化

- **完全配音版大幅改进**：有配音的句子换成中文配音，其余时间保持原声。配音生成时就按原句时长控制长度，评测素材上配音起点偏差的中位数从约 0.5 秒降到约 0.03 秒；配音和原声音量对齐；保留的喘息、亲吻等原声不会被配音盖住，最后一句也尽量在录音结束前说完。音色克隆的参考音频改回 16 kHz 并补回高频，减少破音。装了 IndexTTS-2.5 时，“完全配音版”预设会自动用它。
- **识别更准**：推荐的识别模型改为 anime-whisper，在动画和游戏语音上微调过，耳语和低声台词识别得更准；另可选 Qwen3-ASR 和日语动画/Galgame 微调版。都提供 ModelScope 国内镜像。
- **翻译**：按原句时长给每句定字数预算，太长的译文自动压缩，也可以一键压缩或按要求改译。单句翻译失败不会中断整轨，字幕会先用原文顶上。
- **句子表**：上千句也能流畅滚动；每句可分别试听原声和配音，拖动波形调整起止时间；支持方向键选句、空格试听、回车编辑，以及撤销和重做。
- **多说话人（实验性）**：可以自动区分说话人，每个人分别克隆音色。
- **批量**：识别和配音模型在整个队列只加载一次；中途关掉或断电后再开始，会接着做，已经翻译的句子不会再花一次翻译费用；个别句子失败时作品仍然有成品。
- **其它**：首次使用向导、质量和成品类型预设、读音词典和数字读法、按句多候选配音；英文界面补全了处理进度的翻译。

## 下载与升级

Windows 下载 `ASMR-Dubber-windows-portable-v3.0.0.zip`，完整解压到一个路径短的文件夹，运行 `ASMR-Dubber.exe`。

从 2.x 升级：先关闭程序并备份，将新版本文件覆盖到原程序目录。保留 `.asmr-dubber` 文件夹，其中包含项目、模型和设置。首次启动会检查并更新基础客户端，已经装好的语音模型不用重新下载。

旧项目可以直接打开、继续翻译和导出，已经生成的配音不会失效。项目第一次保存时会升级为 3.0 的格式，并在项目的 `backups/` 文件夹里留一份原文件。升级后的项目不能再用 2.x 打开；要回到旧版，请用这份备份。

已经保存过的设置不会被自动改动；如果原来选的是旧版日语识别模型（如 Faster-Whisper 或 Parakeet），启动时会弹出一次提示，可一键切换到推荐的 anime-whisper（未安装时会自动跳转下载），也可以选择保持原样。

从 1.x 升级：先关掉程序，删除旧文件夹里的 `src` 文件夹和 `ASMR-Dubber-Setup.exe`，再覆盖新版本文件。保留并备份 `.asmr-dubber` 文件夹。

## 已知限制

- 完全配音版依赖人声分离：可能残留一点原声或轻微影响背景音效，识别漏掉的极轻耳语会保留原声。
- 本地配音生成大约需要配音时长的 2 倍时间（RTX 5070 Ti 笔记本显卡实测），IndexTTS-2.5 需要 10 GB 以上显存。
- Edge TTS 依赖 Microsoft 在线服务，可能临时失败或限流，可以只重试失败的句子或换一个音色。
