# ASMR Dubber 1.6.0

## 主要更新

- 网页支持中英文即时切换并记住浏览器选择；Setup、README 和文档提供英文版。
- 新增可选的人声分离，支持独立本地运行环境及云端接口，保留原录音和普通制作流程。
- 新增 RTF（原声空间线索迁移）、双语/替换混音、原声回填和逐句音量/静音。只改混音控制时复用有效配音缓存。
- 无时间轴台本校对改用逐字引用，由程序计算位置；批量匹配无效时逐句重试，仍失败则保留已有文字并标记待检查。
- 字幕每行上限支持 8–500 字符，明确设置保存范围和重新生成要求。
- 修复批量“仅译文字幕”忽略中文字幕的问题：直接采用所选中文时间轴字幕，不再多跑 ASR 或请求翻译密钥。
- 减少界面语言层重复扫描；统一文档导航，补齐音频处理入口。

人声分离和中文替换默认关闭，程序内保留“实验性，不推荐”提示。RTF 独立于人声分离，需要原双声道参考；短参考或静音参考按句降级，不再中断整次混音。

## 下载与升级

Windows 下载 `ASMR-Dubber-windows-portable-v1.6.0.zip`，完整解压后运行 `ASMR-Dubber-Setup.exe`，再运行 `ASMR-Dubber.exe`。请启用长路径并使用短且可写的目录。

Linux x86_64 在源码根目录运行 `bash scripts/linux/setup.sh 推荐`，之后运行 `bash scripts/linux/run-ui.sh`。

升级前停止任务，备份项目、配置和已有成品；保留 `.asmr-dubber` 及外部项目目录。更新后重启程序，只刷新网页不会加载新的 Python 代码。按所改参数重新生成字幕或重新混音，不必无条件重跑全部阶段。
