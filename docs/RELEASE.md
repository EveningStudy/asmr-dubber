# ASMR Dubber 1.5.1

## 主要更新

- AutoFlow 仅字幕文件模式支持双语、仅原文和仅译文，不输出音频或视频成品。
- 设置中可选择沿用音频原名、按字幕内容命名或自定义字幕名称。
- 整理批量处理与自动处理设置，按字幕、配音、视频和时间戳用途分组。
- 加入队列失败时立即显示原因；展开旧结果替换确认入口，保留防覆盖保护。
- Parakeet 默认关闭附加标点恢复，避免识别时隐式下载 FireRedPunc。

## 下载与启动

Windows 下载本 Release 的 `ASMR-Dubber-windows-portable-v1.5.1.zip`，完整解压后运行 `ASMR-Dubber-Setup.exe`，再运行 `ASMR-Dubber.exe`。

Linux x86_64 下载源码包，在根目录执行：

```bash
bash scripts/linux/setup.sh 推荐
bash scripts/linux/run-ui.sh
```

IndexTTS-2.5 从“设置 → 设备与模型”按需安装，不属于默认安装方案。多模型音频片段复核为实验性功能，效果可能不如单模型，默认只提出建议。

## 升级

先停止任务并备份项目、配置和已有成品，再完整覆盖程序文件，保留 `.asmr-dubber` 及外部项目目录。运行 Setup 检查运行环境，然后重新启动程序；只刷新网页不会加载新的程序代码。

句子表现在分页显示，不代表只保存当前页。翻页和定位会保留全部草稿；仍需点击“保存校对表格”写入项目。原有项目文件格式不变。

已有复核记录可通过“只重试音频复核”重新生成。需要重做批量成品时，先核对每轨字幕与语言，再明确选择重做，避免覆盖未备份结果。

安装和操作说明见[安装指南](INSTALLATION.md)、[使用指南](USER_GUIDE.md)及[图文复核教程](AUDIO_REVIEW_TUTORIAL.md)。
