# 使用手册

这篇带你把一个音频从头做成配音成品，以最常见的日语配中文为例。原声是英语或中文、或者想配成英文，步骤完全一样，只是新建项目时选的语言和用的识别模型不同。

照着做一遍大约需要二十分钟，其中大部分时间是等模型跑。

开始之前，请先按[安装与模型](INSTALLATION.md)把程序跑起来，并下载好识别模型和配音模型。

## 1. 准备：填翻译 Key

翻译要用到大模型服务，你需要有其中一家的账号和 API Key。默认用 DeepSeek，便宜，效果也够用。

打开“设置 → 云端服务”，在要用的那一行点“填写”。

![云端服务列表](../assets/screenshots/zh/keys.png)

把 Key 粘贴进去，点“保存”。

<img src="../assets/screenshots/zh/key-dialog.png" width="520" alt="填写 Key">

有两种情况可以跳过这一步：

- 你手上已经有译文字幕，不需要翻译。
- 原声和配音是同一种语言，只想换个声音重新配。

## 2. 新建项目

回到“项目”页，把音频或视频文件拖到“新建”区域，或者点一下选择文件。

![项目首页](../assets/screenshots/zh/home-first.png)

文件上传后会弹出这个窗口：

<img src="../assets/screenshots/zh/new-project.png" width="560" alt="新建项目">

- **音频里说的是**：原声的语言。
- **配音成**：想要的配音语言，中文或英文。
- **文字从哪来**：没有字幕就选“自动识别”。有字幕或台本的话，见[字幕与台本](SUBTITLE_WORKFLOW.md)。

点“创建”。程序会把原文件复制一份到项目文件夹里，你的原文件不会被改动。

## 3. 认识工作区

项目打开后是这个样子：

![项目工作区](../assets/screenshots/zh/step1.png)

- **顶部**是四个步骤：识别、翻译、配音、导出。做完的步骤数字会变成实心。可以随时点任何一步回去改。
- **左边**是句子表格。每一行是一句话，有时间、原文、译文和配音状态。原文和译文可以直接点进去改。
- **右边**是当前步骤的设置和操作按钮。常用的在上面，其余的收在“更多设置”里。
- **底部**是播放条，可以切换听原声、配音，或者两个一起。

右边面板里改的设置只属于这个项目，改完自动保存，没有“保存”按钮。

## 4. 第一步：识别

识别是把音频里说的话转成带时间的文字。

1. 确认“识别模型”。日语音频用 anime-whisper（没装时是 Parakeet），英语和中文用 Faster-Whisper。
2. 点“重新识别”。第一次识别也是点这个按钮。
3. 等它跑完。一小时的音频用显卡大约需要几分钟。

跑完后表格里会出现句子。花几分钟过一遍原文，把明显识别错的地方改掉，因为翻译是照着原文翻的。错在这里，后面每一步都会跟着错。

如果句子的切分不理想（一句话被切成两半，或者两句话粘在一起），可以展开“更多设置”里的“断句”和“无声片段检测”调整后重新识别。

![识别的更多设置](../assets/screenshots/zh/step1-advanced.png)

> **注意**：重新识别会替换掉现有的全部句子，已经做好的译文和配音都要重做。确认原文没问题后再往下走。

## 5. 第二步：翻译

点顶部的“翻译”。

![翻译步骤](../assets/screenshots/zh/step2.png)

1. 确认“翻译服务”是你填了 Key 的那一家。
2. 点“翻译剩余 N 句”。

翻译完成后，译文会填进表格。**译文就是配音要念的稿子**，所以这一步值得认真看一遍：

- 觉得哪句翻得不好，直接点进译文格子里改。
- 译文太长的话，配音会比原句长，后面可能要加速才能塞进去。尽量让译文和原句差不多长。
- 笑声、呼吸声这类没有实际内容的句子不会被翻译，译文是空的，这是正常的。

“翻译剩余”只翻还没有译文的句子，不会动你改过的。“全部重新翻译”会把所有译文重翻一遍，包括你手动改过的，点之前会让你确认。

### 按要求改译

翻得大体对，只是有一类问题想统一改（比如“不要出现‘亲爱的’”“语气更温柔一点”“这些句子太书面了”），可以点翻译页的“按要求改译”：

1. 选范围：当前选中的句子、当前表格筛选（搜索）出来的句子，或全部已翻译的句子。
2. 在“你的要求”里写一句话。需要时勾选“也包括我手动改过的句子”，默认不勾，你亲手改过的句子不会被送去改。
3. 点“开始改译”。程序把这些句子连同相邻句子和你的要求发给翻译模型，模型只返回确实需要改动的句子。

改动不会直接生效。完成后翻译页会出现“改译提议”列表，逐句显示原文、旧译文和新译文：点句子编号可以在表格里定位，“接受”才会写入译文，“拒绝”就保留原样，也可以“全部接受”或“全部拒绝”。接受过的句子会被当作你手动改过的句子，已经生成的配音需要重做；模型认为该句不需要配音的，接受后按“拟声词和无实义声音”的设置处理。

这个功能需要大模型翻译服务（DeepSeek、百炼、OpenAI 等）。DeepL、Google 翻译、Microsoft 翻译只能逐句直译，不支持。如果你在提议出来之后又亲手改了某一句，那一句的提议会在你点“接受”时被丢弃，不会覆盖你的修改。

想让翻译更贴合作品，可以展开“翻译参数”，在“翻译 Prompt”里写上人物关系、称呼和语气。这里还能调上下文句数等参数。改乱了可以点“恢复内置 Prompt”。

![翻译的更多设置](../assets/screenshots/zh/step2-advanced.png)

## 6. 第三步：配音

点顶部的“配音”。

![配音步骤](../assets/screenshots/zh/step3.png)

### 选配音模型

- **IndexTTS2**：模仿原声的音色，需要 NVIDIA 显卡。想要“听起来像原来那个人在说中文”就用这个。
- **Edge TTS**：微软的在线语音，免费，不需要显卡，但声音是固定的那几个，不能模仿原声。
- 其他云端服务见[模型与服务](BACKENDS.md)。

### 选音色参考

用 IndexTTS2 这类克隆模型时，需要告诉它模仿哪个声音。程序会自动推荐一句，你也可以点“更换”自己选。

<img src="../assets/screenshots/zh/reference-dialog.png" width="560" alt="选择音色参考">

在“项目内的句子”里挑一句，点播放听一下。好的参考是这样的：

- 5 到 15 秒长
- 只有一个人在说话
- 是正常说话的声音，不是纯气声或笑声
- 背景音乐和音效比较弱

列表里带“★ 推荐”的是程序认为合适的，带“⚠ 过短”的不建议用。也可以点“选择文件”用项目外的音频当参考。选好后点“采用”。

### 开始生成

点“生成剩余 N 句”。程序会一句一句地生成，右侧能看到进度。

![配音进行中](../assets/screenshots/zh/task-running.png)

生成完的句子，表格最右边会出现播放按钮和时长，点一下就能听这一句。

![配音完成](../assets/screenshots/zh/step3-done.png)

“生成剩余”只会生成还没有配音的句子，和译文被改过的句子。所以听到哪句不满意，改一下译文再点一次就行，不用全部重来。

## 7. 第四步：导出

点顶部的“导出”。

![导出步骤](../assets/screenshots/zh/step4.png)

从上到下几个选项：

- **成品**：选“双语版”就是原声加配音。“替换版（实验性）”就是完全配音版：把有配音的句子里的原人声换成配音，其余时间保持原声，见[混音与空间跟随](EXPERIMENTAL_AUDIO.md#完全配音版去掉原来的人声)。
- **空间跟随**：打开后，配音会跟着原声的左右位置和远近变化。原声是双声道的音声建议打开。
- **保存哪些音频**：除了成品，还可以单独保存一条只有配音的音轨，方便你在别的软件里继续处理。
- **导出内容**：选“音频”正常导出。选“只要字幕”就不生成音频。
- **字幕**：双语、仅译文、仅原文，或者不要字幕。

点“导出”。完成后，文件会出现在“上次导出”里，可以直接试听，也可以点“下载”保存到别处。

![导出完成](../assets/screenshots/zh/outputs.png)

点右上角的“打开文件夹”能看到所有成品文件。

导出这一步的设置（音量、配音时间、空间跟随的强度）改了以后，只需要重新点“导出”，不用重新配音。想调这些的话见[混音与空间跟随](EXPERIMENTAL_AUDIO.md)。

如果导出时提示某一句“没有中文”，说明这句有原文但没有译文。补上译文，或者把这句左边的勾去掉，再导出。

## 8. 改某一句

在表格里点一下某一行选中它，表格下方会出现几个按钮。展开“所选句子”可以看到这一句的详细控制：

![所选句子的控制](../assets/screenshots/zh/sentence-controls.png)

| 想做什么 | 怎么做 |
|---|---|
| 改原文或译文 | 直接点进格子里改，点别处就保存了 |
| 这句不要配音 | 去掉这一行最左边的勾 |
| 调整这句的起止时间 | 直接拖动下方迷你波形左右两侧的蓝色竖柄，或改“开始（秒）”和“结束（秒）” |
| 单独听这句原声或配音 | 点时间列旁的 ▶ 试听该句原声区间，点配音列旁的 ▶ 试听该句配音 |
| 修改这一句的说话人编号 | 在“所选句子”里改“说话人”（例如 `S01`、`S02`），多人项目会按说话人分别选用参考音色 |
| 指定多音字或专名读法 | 配音步骤展开“更多设置 → 读音词典”，每行写一条如 `重来=虫来`（仅改配音读法，不改字幕） |
| 这句配音太响或太轻 | 改“配音音量微调（dB）”，正数变响，负数变轻 |
| 导出时这句不放配音，但保留已生成的 | 去掉“播放配音”的勾 |
| 完全配音版里这句保留原声，或强制去掉原声 | 表格里“原声处理”选“保留原声”或“替换掉原声”，“自动”是有配音就替换 |
| 这句配音念坏了，想再来一次 | 点配音列里的 ↻，只重做这一句。“需要检查”筛选会列出质检没通过和疑似残留原声的句子 |
| 在后面加一句漏掉的话 | 点“新增句子” |
| 删掉这句 | 点“删除句子” |
| 用这句当音色参考 | 点“设为项目音色参考” |

表格上方可以搜索，也可以只看“未翻译”“未配音”“需要检查”的句子。表格采用虚拟滚动，上千句也能直接平滑滚动，下方可点“撤销 / 重做”（`Ctrl+Z` / `Ctrl+Y`），并支持键盘上下选句、空格试听、回车编辑。Windows 本机大文件可点首页“选择本机大文件”直接同盘免复制建项，左下角“退出程序”可安全关闭后台服务。

改完之后要重做哪些步骤：

| 改了什么 | 接下来 |
|---|---|
| 某句的译文 | 配音步骤点“生成剩余”，再导出 |
| 配音模型、音色参考 | 全部重新配音，再导出 |
| 音量、配音时间、空间跟随、字幕排版 | 只需要重新导出 |
| 重新识别 | 翻译和配音都要重做 |

## 9. 中途停下和接着做

- **想停下正在跑的任务**：点右侧任务旁边的“暂停”。已经做完的部分会保留。
- **想接着跑**：点“继续”，或者再点一次那一步的按钮。它只会做剩下的。
- **关掉程序再打开**：项目会出现在首页的“最近”里，点一下就回到上次的地方。

![最近的项目](../assets/screenshots/zh/home-recent.png)

关掉启动程序时出现的那个黑色窗口，程序就停了。只关浏览器页面不会停，重新打开 `http://127.0.0.1:7860` 就能回来。

## 首次启动向导、预设与任务面板

- **首次启动向导**：第一次打开程序会出现三步向导：检测硬件并给出推荐配置、下载模型（和“模型”页是同一套下载，可暂停、续传）、填翻译 Key 并点“保存并测试”。做完后直接进入新建项目。点“稍后再说”也会记住，以后不再自动弹出；想再走一遍，到“设置 → 通用 → 首次启动向导”点“重新打开”。
- **预设**：项目页右侧和设置页顶部有两组预设。质量档位“快速 / 均衡 / 最佳质量”：快速更快、更省显存（分块更短、翻译带的前后文更少、不做配音质检、完全配音版少做几步修饰），最佳质量就是出厂默认值。成品类型“双语版 / 完全配音版”：完全配音版会打开人声分离，需要先装好分离模型。预设只改下面列出的参数，不会换识别或配音模型。选中的预设与当前值不一致时，会列出“与预设不同的参数”。
- **参数搜索**：预设上方的搜索框按中文名、英文名或参数名过滤，搜索时各步骤和各设置页的匹配项一起列出。
- **全局任务面板**：任何页面的右下角都会显示正在运行的任务、进度和剩余时间的估计，可以点“暂停”。下载类任务因为按文件计进度，不给估计。

## 翻译漏句与重试

有实义的句子返回空译文时，程序会自动单句重试。仍失败的句子保留启用，不会拖累其余批次：所有批次跑完后，翻译面板会显示“翻译结果”卡片（成功、跳过、失败的句数和失败原因），点句子编号可在表格里定位，“只重试失败句”或“把这些句子设为不配音”一键处理。连续 3 批失败或密钥、额度、权限错误（HTTP 401/402/403）才会提前停止，已完成的译文都已保存。拟声词和无实义的短声音由模型标为 sound，按“拟声词和无实义声音”设置处理：跳过并保留原声（默认）、写罗马音只进字幕、或保留原文只进字幕。“全部重新翻译”会逐句替换并保留旧译文直到新译文到手，开始前自动备份，可用“恢复上一版译文”撤回；你手动改过的句子默认不被覆盖。旧版误停用的实义句子可点“恢复误跳过的句子”，也可逐句勾选，行颜色和剩余数立即更新。无需新增空句或退出重进。纯笑声、呼吸等非语言片段仍可跳过。
