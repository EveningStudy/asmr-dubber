# 音频处理：RTF、人声分离与逐句混音

人声分离与中文替换：实验性，不推荐；默认关闭。人声分离可能误删气声、呼吸和口腔声，背景可能残留日语；RTF 可能改变音色、相位和近耳感。没有“纯中文且无损还原原作”的保证。

## 操作入口

分离位于“常规”和“ASR”之间的“人声分离（实验性）”页；RTF、混音方式和原声回填位于“混音与字幕”页。分离与 RTF 是两个独立开关，默认均关闭。RTF 不要求分离，但要求原双声道参考。关闭分离时中文替换不可选；已有替换设置与关闭分离冲突时，保存会明确拒绝，不自动切换。原声回填仅在替换模式显示，页面摘要列出最终混音组成。

1. 按需开启分离，选择已下载的模型，保存到当前项目或两者，再运行 ASR。识别与复核使用分离人声，原录音不改动。
2. 正常翻译、校对、配音。TTS 参考仍使用原项目音频，不把分离损伤自动传给音色克隆。
3. 按需开启RTF，再混音。RTF 使用原双声道的对应片段分析左右频谱、相位及相对电平，不使用 HRTF 或 Meta 模型。
4. 双语模式保持“原音 + 中文”；中文替换模式使用“分离背景 + 中文”，必须开启分离。

## 两种成品的中文响度

项目“导出 → 更多设置”提供“双语版中文响度”和“替换版中文响度”两个独立区域。

- 双语版沿用旧项目的响度参数，默认相对原始录音片段 -8 dB。
- 替换版默认相对分离后的原人声 0 dB，自动匹配上限为 -20 RMS dBFS、单句峰值上限 -6 dBFS；旧项目没有替换版参数时使用这些默认值。
- 两组分别选择跟随原声、统一响度或保留 TTS 原始音量，各自设置增益、响度范围和峰值保护。0 dB 是匹配目标，仍可能受响度上下限和峰值保护限制。
- 批量同时生成双语版和替换版时，分别应用对应区域。TTS 缓存复用；两版中文中间轨和响度缓存独立。
- 修改即保存；项目参数与新项目默认值分别调整。重新混音即可，无需重新生成 TTS。

## 原声回填

本文部分控件沿用“中文”名称；TTS 目标选择英文时，同样处理英文配音。语言切换与重新合成要求见[配置参考](CONFIGURATION.md#输入与配音目标)。

### 表格逐句控制

单个作品的句子校对表格右侧增加四列：原声开关、原声音量微调、播放中文配音、中文音量微调。

- 原声开关默认“沿用设置”：双语模式保留，替换模式沿用回填规则；可以逐句强制保留或关闭。**原声开关和音量仅在开启人声分离时生效**，只修改人声轨，背景不重复叠加。
- 音量微调默认 0 dB，叠加在原有全局处理上；负数减小、正数增大，范围 -60～+12 dB，最终仍受峰值保护。
- “播放中文配音”只控制最终声音；不同于“启用中文处理”，不会删除译文或配音缓存，也不表示重新翻译。
- 修改后保存表格，再点击“混音与输出”即可；不需要重做 ASR、翻译或 TTS。重叠原声区间不叠加多份人声，显式关闭优先。

默认不回填。手动模式输入句子 ID（逗号/空格分隔）；自动模式选取禁用或无可配音中文的句子，包括可能被过滤的内容。**这不是非语言发声分类器**，可能回填日语台词，必须试听。手动选择已配音句子可能形成双语重叠。

回填只加入分离的人声，不复制整段原混音，因此不会把背景叠加两遍。未识别出的非语言声音若被分离模型移入人声轨，仍可能丢失；当前只能回填有句子时间范围的区域，可在句子表增加范围再按 ID 选择。

## 本地后端

使用独立环境 `.asmr-dubber/runtimes/separation/.venv`，不修改主 ASR/TTS 环境。安装 audio-separator 0.47.0，支持其 Mel/BS-RoFormer、MDXC、MDX、VR、Demucs 模型接口。模型目录 `.asmr-dubber/models/separation`。

本机基线为 `vocals_mel_band_roformer.ckpt`（Kimberley Jensen）。它是歌曲人声分离模型，不是针对 ASMR 训练的对白/音效分离器。Bandit、SAM Audio 未直接集成本地推理，不能仅填其权重名使用。

架构参数只对相应模型生效。高级 JSON 覆盖各架构公开推理参数，不能修改训练网络结构。其他权重需要各自许可，部分模型有限制；清单里出现不等于已经下载或已经实测。ONNX 模型当前独立环境使用 CPU 提供程序，RoFormer 的 PyTorch 路径可使用 CUDA。

下载必须在设置中主动确认：来源为 PyPI、PyTorch、GitHub/Hugging Face，不受原 Setup 的 ModelScope 镜像覆盖。默认模型固定哈希检查；其他模型记录本机下载校验清单。推理阶段禁止隐式下载，缺文件会报错。

## 批量输出与缓存

批量任务可选双语成品、替换配音成品或两者，沿用入队时保存的分离、RTF、混音与回填设置。替换配音必须开启分离；原声加字幕和仅字幕任务不运行配音、分离或 RTF。完整选项见[批量输出选择](USER_GUIDE.md#批量输出选择)。

- **分离**：一次本地分离处理内只加载一次模型，按块顺序推理，不是每块重载。取消或超时后保留已校验的分块；重试加载一次模型并继续未完成部分。模型不会跨任务永久占用显存。
- **RTF**：双语版与替换版复用有效的配音中间轨。校验原声参考、逐句音频、时间排程、音量和 RTF 参数；变化或缓存损坏时重算。只改变背景组合不要求重新生成相同的配音轨。
- **输出**：项目内两版分别写入 `output/bilingual/`、`output/replace/`，字幕位于对应 `subtitles/` 子目录。不会先写一个通用成品再复制备份；用户指定的最终导出目录仍可保留独立成品副本。

项目原素材、分离的人声与背景、RTF 参考和混音输出用途不同，不应按“大文件”一概删除。长音频的未压缩 WAV 仍可能占用较多空间；复用 RTF 会保留一份可重建中间轨。使用 **设置 → 存储与清理** 扫描，确认后清理：安全缓存不移除完整分离结果；手动清理分离结果会增加下次处理时间。见[清理范围](CONFIGURATION.md#存储与清理)。旧版本的输出副本不会被自动删除。

## 云端接口

- Replicate：API Key、固定版本 ID、输入音频字段、人声输出字段和额外参数。输出字段相对 prediction 的 `output`，可用 `vocals` 或数组索引 `0`，实际取决于模型。每块以内联音频提交，限制 8 MiB；建议外层分块不超过 30 秒。
- 自建 HTTP：POST multipart；文件字段可配置，另有 `model` 和 JSON 字符串 `parameters`。响应必须是 JSON，指定路径给出人声轨 HTTPS 下载 URL。

云端必须显式同意上传；可能计费。失败后不自动重发任务。输出下载不转发 API Key、不跟随重定向。没有实际账户验证过的服务不能视为生产可用；上传前核对作品授权和服务隐私政策。

## 参数与恢复

RTF 遇到不足 0.1 秒的参考或静音参考时，只对该句降级为有限左右电平差（无信号时居中），不估计相位；中文文字、时长与排程不变，并在日志记录“RTF 降级”。不借用邻句原声，不因此中断整次混音。非有限采样或损坏音频仍明确报错。

分离外层按块运行；修改模型、设备或分离参数会生成新的项目内缓存。有效块可复用，原人声与背景总长度保持一致。背景为原音减去估计人声，仍可能有分离伪影。

RTF 在现有中文时长排程和响度处理后执行：强度控制干湿比，电平/染色强度控制原录音线索迁移，FFT 与步长控制时频分辨率。仅支持双声道原音，单声道/多声道不会伪造空间信息；修改 RTF 参数只需重新混音。

分离和 RTF 的默认值是资源受限的实验起点，不是听感最优参数。先用十几秒素材试听，再用于整部作品；不要直接删除缓存、项目或源文件来排障。
