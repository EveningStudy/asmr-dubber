# 配置指南

设置保存在 `.asmr-dubber/config/settings.json`。保存设置时，当前项目会取得新的设置快照；

## 设备与模型

ASR 和 TTS 分别显示状态表与安装/修复入口。ASR/TTS 设置页还会列出本机已确认可用的具体
模型；检测过程只读取本地文件，不会自动联网或加载模型。

后端状态：

- **可用**：运行时和必要模型完整。
- **未安装**：缺少运行时、包或命令。
- **模型不完整**：文件校验失败或下载未完成。
- **外部服务**：需要配置并启动独立服务。
- **不兼容**：后端未声明支持当前平台或设备。

安装器只处理所选后端。ASR 和 TTS 串行加载，显存需求不需要相加。

下载与网络、总设置、ASR、翻译和 TTS 页面均可单独恢复默认值。重置后需要点击“保存全部
设置”才会生效；此操作不会删除已保存的 API Key 或模型文件。

推荐顺序：

1. Parakeet CTC 1.1B JA GAL；
2. Parakeet TDT/CTC 0.6B JA；
3. Kotoba-Whisper v2.2；
4. Faster-Whisper large-v2；
5. Qwen3-ASR 作为 CUDA 替代或多模型校对来源。


## 下载与网络

- **Hugging Face Endpoint**：模型下载端点；留空使用官方服务。
- **Python 包索引**：PEP 503 `/simple` 索引；留空使用官方 PyPI。


## 项目目录

默认项目位于 `.asmr-dubber/projects`。

`performance.json` 记录阶段耗时、后端、句数、缓存命中和输出大小。

## 中文开始位置

默认最长提前 5 秒、句长上限 50%。正数提前量为：

```text
min(逐句或全局秒数, 日语句时长 × 全局百分比 / 100)
```

- `0`：从日语句末开始。
- 负数：在句末之后等待，百分比不再限制。
- 表格中的逐句秒数覆盖全局秒数，但仍受全局百分比限制。

程序不会为避让其他日文或中文自动移动句子。

## 中文响度

开启“自动跟随每句日语的局部响度”后：

1. 计算日语时间窗内的有效 RMS；
2. 加上“中文相对原句的响度”；
3. 限制在可听下限和安全上限之间；
4. 应用最终微调增益；
5. 对单句和叠加后的中文轨做峰值保护。

默认值：

| 参数 | 值 |
|---|---:|
| 相对原句 | -4 dB |
| 可听下限 | -42 dBFS |
| 安全上限 | -30 dBFS |
| 最终微调 | 0 dB |

所有增益和峰值处理只作用于中文轨。完整 float32 中文中间轨默认在最终混音后删除；逐句缓存保留。

## ASR

界面只显示当前后端支持的参数和设备。

- **批大小**：默认 1。增大可提高吞吐和显存占用，部分模型会出现细微结果差异。
- **Beam Size**：仅 Whisper 类后端使用。
- **VAD**：默认关闭，避免过滤耳语和低响度台词。
- **初始提示词**：用于后端支持的专名或热词。
- **Parakeet 解码器**：仅 0.6B 使用；1.1B 固定 CTC。
- **Parakeet 分块上限**：保持 0 使用运行时默认流式编码。
- **Kotoba 分块**：默认 15 秒。

切换 ASR 只影响新项目，或显式强制重新识别的项目。

### 多模型校对

- “额外参与比对的 ASR”只显示已安装运行库且本地模型文件完整的选项。
- 各模型串行运行，总耗时近似相加。
- 背景信息只用于消歧，不作为台词证据。
- 漂移容差只决定候选时间窗；最终边界来自被引用候选。
- Prompt 必须保留 JSON、`window_id` 和 `evidence_ids` 合同。
- 翻译供应商必须是 LLM，不能使用普通机器翻译 API。

## 翻译

默认 Prompt 要求：

- 严格保持 ID 和顺序；
- 输出可朗读的简体中文；
- 纯笑声、哭声、呼吸、喘息、呻吟、亲吻声、拟声和无意义重复音返回空字符串；
- 混合句只翻译实义内容；
- 保留成人或耳语台词的实义信息。

LLM 参数默认 `temperature=0.1`、`top_p=1.0`。翻译最多按 16 句和约 4000 日文字符分批；长度不足时
自动二分。点击“补译空白中文”不会覆盖已确认译文。

DeepL、Google 和 Microsoft 的供应商专属参数只在对应供应商被选择时显示。

## TTS

### 参考来源

- **项目内参考句**：识别翻译后在项目页试听并选择。
- **外部参考音频**：复制到 `.asmr-dubber/config/references`，可跨项目使用。

推荐 4–15 秒、单一说话人、无明显 BGM、非纯气声的参考。要求参考文本的后端必须填写准确文本。

### IndexTTS2

IndexTTS2 使用独立运行时。音色参考来源和情绪参考来源彼此独立：默认音色使用项目页选中的
参考句，情绪使用每句话对应的日文原句。外部音色与外部情绪音频分别上传；只有选择“文本情绪”
时才显示情绪描述文本。模型目录和 `config.yaml` 默认由安装器配置，不需要手工修改。

### 参考模式

- **统一声纹，仅音色参考**：句间音色最稳定。
- **逐句参考**：适合多角色或特定实验，容易受片段质量影响。
- VoxCPM2 专属语气和 Hi-Fi 模式只在 VoxCPM2 中显示。

IndexTTS2 不使用上述通用参考模式，而是在自己的参数区分别选择音色与情绪来源。

## 密钥

密钥以明文保存在 `.asmr-dubber/config/secrets.json`，与普通设置分离。密码框不回显已保存值；留空保存会保留旧值，使用“清除”按钮才会删除。

Linux 文件权限为 `600`。Windows 依赖项目目录的账户 ACL。不要共享 `.asmr-dubber`，也不要把它提交到 Git。

可选环境变量：

```text
DEEPSEEK_API_KEY
OPENAI_API_KEY
ANTHROPIC_API_KEY
GEMINI_API_KEY
DEEPL_API_KEY
GOOGLE_TRANSLATE_API_KEY
AZURE_TRANSLATOR_KEY
```
